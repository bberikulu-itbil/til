# Тіл

Life Hub экожүйесінің тіл үйрену қосымшасы: ағылшынша сөздік және қайталау карточкалары.

- Сайт: https://bberikulu-itbil.github.io/til/
- Аккаунт ортақ: Life Hub-қа кірген болсаң, мұнда да кірген боласың (екі сайт бір доменде, бір Supabase жобасында).
- Сөздер Hub-тың `items` кестесінде сақталады (`app = 'lang'`), сондықтан Hub ассистентіне «… сөзін сөздікке қос» десең, сөз осында бірден шығады.

## Қайталау қалай жұмыс істейді

Leitner жүйесі (`srs.js`): «Білдім» десең, сөз келесі қорапқа өтеді және ұзағырақ күтеді (1 күн → 3 күн → 1 апта → 2 апта → 1 ай → 3 ай). «Білмедім» десең, сөз басынан басталады. 2 апталық қорапқа жеткен сөз «үйренілді» деп саналады. Күніне ең көбі 10 жаңа сөз шығады.
